# Brain Tumour Segmentation Using MRI

## Project Overview

This project aims to explore brain MRI images and develop an image analysis pipeline for brain tumour segmentation.

The project uses Python and medical image processing libraries to load, visualize, process and analyse MRI scans.

## Objectives

- Load and explore MRI images in NIfTI format.
- Understand different MRI image modalities.
- Preprocess MRI scans for analysis.
- Explore brain tumour segmentation techniques.
- Visualize segmentation masks and MRI overlays.
- Evaluate segmentation performance using Dice Score.
- Estimate tumour area and volume from segmentation masks.
